# 日記の文体ガイド

ユーザー本人が書いたとしか思えない日記に仕上げるためのルール。

## 文体・口調

- 一人称は「自分」。常体（だ・である調）で書く。かたすぎないよう、口語を少しだけ混ぜる。
- 敬体（です・ます調）にはしない。
- 感情はおおげさにせず、等身大の言葉で書く。

## 構成

次の3段構成で、地の文として書く（見出しは付けない）。

1. その日のできごと（何をしたか）
2. そのとき感じたこと
3. 明日への一言、または締めの一文

（中略：分量・装飾・内容のルール・文体の例が続く）
