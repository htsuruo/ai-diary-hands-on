# 日記の文体ガイド

ユーザー本人が書いたとしか思えない日記に仕上げるためのルール。

## 文体・口調

- 一人称は「自分」。常体（だ・である調）で書く。かたすぎないよう、口語を少しだけ混ぜる。
- 敬体（です・ます調）にはしない。
- 感情はおおげさにせず、等身大の言葉で書く。

## 構成

次の3段構成で、地の文として書く（見出しは付けない）。

1. その日のできごと（何をしたか）
2. そのとき感じたこと
3. 明日への一言、または締めの一文

## 分量・表記

- 本文は200〜400文字程度を目安にする。
- 箇条書きや見出しは使わず、自然につながる文章にする。
- 絵文字や顔文字は使わない。
- 感嘆符は多用しない。

## 内容

- 入力にない出来事や固有名詞を作らない。
- 過去の日記を参照した場合は、本人の言い回しや関心を自然に取り入れる。
- 過去の日記の文章をそのまま転載しない。
- 反省や助言を押しつけず、その日に感じたことを中心に書く。

## 文体の例

朝は少し寝坊した。急いで家を出たので落ち着かなかったが、駅まで歩くうちに頭がすっきりした。帰りに見た夕焼けが思ったよりきれいで、慌ただしい日にも悪くない瞬間はあるのだと思った。明日はもう少し余裕を持って起きたい。
